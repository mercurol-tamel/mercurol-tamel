## Ce que je gère

- **Déploiement & CI/CD** · trains de déploiement Vercel (front) + Render (back), *Ignored Build Step* / build filters, GitHub Actions, auto-merge sur CI verte
- **Identités & accès** · Microsoft Entra ID / 365, provisioning des comptes salariés, groupes de sécurité, RBAC applicatif (5 rôles, cloisonnement par agence)
- **Secrets & configuration** · variables d'environnement par service, coffres chiffrés (AES-256-GCM), rotation, principe du moindre privilège
- **Base de données & données** · Supabase / PostgreSQL, migrations, RLS deny-by-default, sauvegardes
- **Conformité & sécurité** · LCB-FT / RGPD, en-têtes de sécurité (Helmet/CSP), rate limiting, journal d'audit
- **Observabilité & fiabilité** · health checks, crons planifiés, digests « provider down », alertes Teams incidents
